# شنو الكلمة؟

An Iraqi-dialect word game: guess the five-letter word in six tries.

- `index.html`: the whole game (board, keyboard, daily word, practice mode, streak)
- `words.txt`: accepted guesses (about 284k Standard Arabic and Iraqi words, gzip + base64)

Play: https://ali-hayder-ab.github.io/shno-alkalima/
